# 图 4.1（泛化实验热力图）配色规律

> 从原图 `images/ch4_generalization.png` 逐格像素提取，用于 thesis 中 Table 4.5（LaTeX 彩色表格版）。

## 一、核心规律

1. **每个面板独立线性归一化**：
   - NBD：`t = (v - 0.023) / (0.668 - 0.023)`
   - NRD：`t = (v - 1.7) / (28.2 - 1.7)`
2. **颜色 = 纯色相 + 白色混合**（即 xcolor 的 `色相!饱和度!white` 语法）：
   - 绿区（t 小）：`green!10~30!white`
   - 黄区（t 中）：`yellow!8~36!white`（原图黄色略偏暖，比纯混合差 4–8/255，表内用原图精确 hex）
   - 红区（t 大）：`red!50~80!white`
3. **饱和度随 t 的走向**：t=0 → 绿 30%，先降到绿 10%（t≈0.05），过渡到黄 8%（t≈0.07），黄区升到 36%（t≈0.35），跳红 50%（t≈0.5），红区升到 80%（t=1）。
4. **文字全部黑色**（红格上也是黑字，与原图一致）。

## 三、更新数值时如何取色

1. 按所属面板计算 `t = (v - min) / (max - min)`
2. 在对应面板的对照表中找两个相邻的 t 和颜色，用 xcolor 混合插值：`\cellcolor{色A!p!色B}`（p 为 0–100 的混合百分比）
3. 若 t 落在面板之外（v < min 或 v > max），用端点色并**更新该面板的 min/max 归一化常数**（即重新归一化所有格子——两端点颜色不变，中间格子会整体移动）

## 四、原图已知瑕疵（有意保留或修正）

- NBD 面板 0.643（t=0.961）用的是 hr50，比 0.504（hr55）还浅——原图色阶不单调的噪声点；表格版按原图保留
- NRD 黄区 12.6（t=0.411, hy32）比 8.9（t=0.272, hy36）浅——同上，属原图量化噪声
- BiLSTM₆₀ 的 NBD 行与 LightGBM 行数据完全相同（待博士生数据），颜色自然相同
- 若想要严格单调的色阶，可改回 §一 的平滑锚点曲线（绿→黄→红三段线性）
